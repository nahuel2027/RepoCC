# Contratos del Sistema - SDD

## 1. Reglas de Negocio Globales
* **Visibilidad:** El listado de eventos es público por defecto.
* **Filtros Temporales:** El sistema debe permitir filtrar eventos "A futuro" y "Pasados".
* **Cupos:** Los eventos pueden tener cupo mínimo y máximo definido.
* **Plazos:** Cada evento posee una fecha límite de inscripción.

## 2. Roles de Usuario
* Se deben gestionar tres roles principales: Organizador, Participante y Disertante.

## 3. Formato de Certificados e Informes
* El sistema debe ser capaz de generar certificados de asistencia, aprobación y calidad de autor/expositor.
