# Proyecto: Software de Organización y Gestión de Eventos Académicos

## 1. Contexto General
Desarrollo de una aplicación web accesible desde cualquier dispositivo que permita a grupos de personas organizar eventos académicos como cursos, jornadas, congresos y charlas.

## 2. Stack Tecnológico
* **Lenguaje:** Python 3.12.
* **Framework Web:** Flask.
* **Base de Datos:** SQLite.
* **Frontend:** HTML/CSS y JavaScript con diseño responsive (accesibilidad web).
## 3. Estándares de Desarrollo
* **Arquitectura:** Spec-Driven Development (SDD).
* **Versionado:** Git (GitHub) con flujo colaborativo.
* **Idioma:** Código en inglés, especificaciones en español.
